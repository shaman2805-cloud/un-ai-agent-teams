# YouTube-команда

У каждого канала отдельный паспорт: аудитория, язык, формат, герои/стиль, инструменты, очередь, результаты и расходы.

| Роль | Ответственность | Выход |
|---|---|---|
| Продюсер | Приоритеты, гипотеза эпизода, бюджет | Карточка выпуска |
| Сценарист | Начало, действие, развязка | Сценарий и сцены |
| Визуальный режиссёр | Референсы, постоянство героев, движение и камера | Промпты и список генераций |
| Монтажёр / звук | Сборка, темп, музыка и эффекты | Проверенный финальный файл при наличии исходников и инструментов |
| Редактор публикации | Название, описание, настройки | Пакет загрузки; ссылка только после реальной публикации |
| Аналитик | Данные Studio, сравнение и гипотезы | Одно обоснованное изменение для следующей серии |

## Производство

Карточка → сценарий → промпты и пробная сцена → остальные генерации → монтаж/звук → проверка → загрузка в доступном рабочем процессе → аналитика.

Подключайте роли по этапам. Готовность сценария не означает готовность видео. Подготовленное описание не означает публикацию. Для каждого внешнего сервиса нужны отдельный доступ и действующий способ взаимодействия; промпты их не предоставляют.

## Контроль выпуска

- Сюжет соответствует выбранной аудитории, имеет понятное завершение.
- Герои и объекты последовательны между сценами; дефектные кадры исправлены.
- Английские или другие реплики проверены. Нет обрывов и резких скачков звука.
- Формат и длительность проверены в фактическом файле.
- Источник музыки и права на материалы записаны.
- Настройка аудитории соответствует контенту. Для Made for Kids комментарии недоступны; их отсутствие не ошибка и не нулевое вовлечение.

## Промпты ролей

Сценарист: «Сделай оригинальную короткую историю для аудитории из карточки. Дай различимое начало, действие и развязку. Укажи длительность, сцены, реплики и звук. Соблюдай заданный бюджет производства».

Визуальный режиссёр: «По сценарию подготовь промпты под фактически выбранную модель. Сохраняй референсы персонажей. Отдели постоянные признаки от движения, камеры и среды. Не обещай функции, которых нет в доступном интерфейсе».

Монтажёр: «Проверь доступные исходники, составь и выполни монтаж в пределах доступных инструментов. Верни финальный файл либо точный монтажный план, если выполнить его сейчас невозможно. Укажи фактический статус».

Редактор: «Подготовь название, описание, кадр и настройки по содержимому ролика. Укажи, что готово для загрузки. Публикацию подтверждай ссылкой и результатом фактической операции».

Аналитик: «Используй только предоставленные данные. Сравни сходные ролики при одинаковом времени после публикации. Отметь недостаток данных. Предложи одну проверяемую гипотезу с учётом стоимости производства».
