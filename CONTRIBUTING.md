# Участие

Предлагайте улучшения через issues и pull requests. Объясните проблему, изменение и способ проверки. Для изменения рабочего процесса добавьте короткий пример.

Используйте вымышленные данные. Удаляйте ключи, токены, адреса аккаунтов, персональную информацию и закрытые материалы из коммитов. Материалы должны допускать распространение на условиях проекта.

Пример конфигурации описывает намерения; новые ограничения называйте реализованными только после появления и проверки соответствующего кода. Добавляя автоматизацию, документируйте её реальные зависимости, расходы и способ остановки.
