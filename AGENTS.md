# Repository instructions

This is a public, provider-neutral starter kit. Keep examples fictional and remove personal data, account identifiers, credentials, private product code, and analytics exports from contributions.

- Preserve the distinction between prompts/configuration and implemented runtime capabilities.
- Keep development and YouTube tasks, materials, and resource accounting separate.
- Use one worker for small changes. Delegate only independent tasks when requested and supported by the environment.
- Coordinate ownership before editing shared files. Verify the complete affected user workflow when implementation code is added.
- Do not introduce new external dependencies for the local task generator without a concrete need.
- Never claim a video was generated, uploaded, or published without an actual artifact or tool result.
- Treat example budget fields as configuration, not a spending authorization or an enforced platform limit.
- Keep README.md and README.en.md consistent when changing scope or setup.
